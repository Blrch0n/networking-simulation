# 5–7 минутын танилцуулга

Урьдчилан `make setup && make demo`; интернет суурь зурагт ашиглагдана. Browser [http://127.0.0.1:8000](http://127.0.0.1:8000). Lab эхлүүлэх бол `make lab-up && make lab-check`, дараа нь `make stop && FIBER_LAB_ENABLED=1 make demo`. Эхлээд бодит lab шалгалт үнэхээр passed эсэхийг үз.

1. **0:00–0:45** — “Нийслэл ба 21 аймгийн төвийг холбох шинэ сүлжээ төлөвлөж байна. Цэгүүд GeoNames; тасархай шугамууд замын трасс биш, геодезийн ойролцоо.” MST сонго. 21 холбоос, 21 гүүрийг тайлбарла. Нэг кабель тасрахад мод сална.
2. **0:45–1:30** — “Хамгаалалттай” сонго. 28 холбоос, 0 гүүр. “Энэ нь heuristic, minimum global optimum биш. Нэг логик холбоосын тасралтыг даана; газарзүйн коридорын бие даасан байдал баталгаагүй.” Бүрэн mesh 231 холбоосыг товч харьцуул. Хамгаалалттай горимд буц.
3. **1:30–2:15** — Улаанбаатар → Ховд маршрут сонгоод тоглуул. Ногоон урсгал нь сонгосон полилиний дагуу хөдөлнө. RTT нь тархалтын тооцоо, бодит ping биш. “Кабель сонгох” жагсаалтаас Улаанбаатар–Дархан холбоос сонго.
4. **2:15–3:00** — Кабель тасал. Илрүүлэлт + дахин тооцоолол 3 загварчилсан секундийн дараа маршрут солигдохыг үз. Хосын RTT, маршрут, гүүр, хүрэх хот өөрчлөгдөнө. Түр зогсоох, нэг секунд алхуулахыг харуул. Бүгдийг сэргээ.
5. **3:00–3:45** — Нэг хот сонгож тэжээл тасал. Энэ нь single-link хамгаалалтаас өөр баталгаа болохыг тайлбарла. Хүрэх боломжгүй үед RTT “—”. Урсгал ×5 дарж overload flag харуул. Сэргээ. “Коридор” энэ demo-д тусдаа placeholder тул бодит shared trench/SRLG туршилт биш гэдгийг хэл.
6. **3:45–5:30** — Бодит OSPF лаборатори tab. Lab идэвхтэй үед UB router-ийн OSPF хөрш, route, loopback ping унш. UB–Дархан тасалж acknowledgement үз. 4–6 бодит секундийн дараа дахин хөрш/маршрут/ping унш. Сэргээж FULL ба ping шалга. Timestamp, raw output хадгалагдсан байдлыг харуул. Lab unavailable бол алдааг шууд үзүүлээд “Энэ орчин Docker эрхгүй тул бодит шалгалт хийгдээгүй” гэж тод хэл; simulation-ийг FRR үр дүн гэж бүү танилцуул.
7. **5:30–6:30** — Одоо байгаа сүлжээ: ICN тайлангийн эх сурвалж ба GIS трасс байхгүй тухай empty state. Өгөгдлийн tab: provenance, лиценз, unknown DEM/голын гарц. JSON/GeoJSON/CSV экспорт. “Дараагийн шат: бодит corridor GIS, DEM, SRLG, MILP, өргөтгөсөн lab.”
