# Багшид үзүүлэх 5–7 минутын дараалал

Live: https://networking-simulation-beta.vercel.app/. Локал: `make setup && make demo` → http://127.0.0.1:8000. «Өгөгдөл засах → Анхны 22 хотыг сэргээх», эхлэх Улаанбаатар, хүрэх Ховд сонгоно. Энэ reset нь зөвхөн demo-ийн browser graph-ийг сэргээнэ.

1. **0:00–0:40 — Асуудал ба граф.** Монголын 21 аймгийн төв + Улаанбаатар = 22 орой. Кабель нь чиглэлгүй, уртаар жинлэсэн ирмэг. 231 боломжит хос; геометр нь бодит trench биш, геодезийн ойролцоо.
2. **0:40–1:30 — MST.** Улаан MST сонго. 21 кабель, 3952.29 км, 21 гүүр. Kruskal бүх боломжит кабелиас minimum length spanning tree олно. «Сонгосон замд тасралт турших». Холболт салж, бүх сүлжээний RTT “—”. Эхлэх хотоос хүрэхгүй хотуудыг үзүүл. «Сэргээх».
3. **1:30–2:30 — 2-Edge.** Цэнхэр 2-Edge сонго. 29 кабель, 6338.17 км, 0 гүүр. Энэ нь MST-д урт/арилгах-гүүрийн тоо хамгийн бага кабель нэмэх heuristic. 60.37% урт нэмсэн; глобал optimum гэж хэлэхгүй. Тасралт турших: нөөц зам гарна, before/after зам ба RTT-г харьцуул. «Сэргээх».
4. **2:30–3:20 — Нэг кабелийн бүх шалгалт.** «Бүх кабелийг шалгах»: 29 туршилт, 29 холбоотой, 0 салсан. Worst RTT 24.64 ms, Алтай–Баянхонгор тасрахад. Энэ тооцоо нь өмнөх cut-ийг давхар нэмэхгүй, эрүүл суурь загвараас тохиолдол бүрийг тус тусад нь шалгасан. 50 ms нь сонгосон нэг зам биш, бүх хосын max. MST-д 0/21 connectivity, Full Mesh-д 231/231 гэдгийг хүснэгт/шалгалтаар үзүүл.
5. **3:20–4:00 — Харьцуулалт.** Ногоон Full Mesh: 231 кабель, 152750.58 км; энэ нь зардал ихтэй бүрэн хосын граф. Харьцуулалтын урт/нэмэлт хувь/гүүр/max RTT/хамгаалалт багануудыг тайлбарла. Хэрэглэгч кабель устгавал Full Mesh нь зөвхөн үлдсэн candidate graph болно.
6. **4:00–5:20 — FR-1.2 засвар.** «Өгөгдөл засах»-д `demo-city`, `Туршилтын хот`, 48.1, 106.1 оруул. «Бусад хоттой тооцоолсон кабель үүсгэх» сонгоод хадгал: 23 хот, 253 хос. Нэр/координат засах, нэг кабелийн урт өөрчлөхөд гурван сүлжээ дахин тооцоологдохыг үзүүл. Урт нь user assumption, coordinate edit уртыг хадгалдаг. Устгах, undo, refresh persistence үзүүл. Эцэст анхны өгөгдөл сэргээ.
7. **5:20–6:10 — Тайлбар ба хүрээ.** «Аргачлал ба хязгаарлалт»-д Tarjan `low[v] > discovery[u]`, Dijkstra, `RTT=км×0.01` томьёо. Router processing/queueing ороогүй. Нэг логик кабель тасрах хамгаалалт нь хотын гэмтэл, shared trench эсвэл хоёр замын физик бие даасан байдлыг нотлохгүй.
8. **6:10–7:00 — Optional real OSPF.** Зөвхөн локал lab үнэхээр available, `make lab-check` passed бол хөрш/route/loopback ping, cut/restore үзүүл. Docker permission denied бол «бодит lab шалгалт skipped» гэж хэл. Графын нөөц замыг жинхэнэ FRR convergence/ping гэж бүү танилцуул. Vercel дээр real lab товч зориуд байхгүй.

Шинэ хэмжилт: `docs/planning-results.json`, `docs/planning-performance.json`. Хуучин 28-кабелийн screenshot/measurements нь архив бөгөөд одоогийн алгоритмын үр дүн биш.
